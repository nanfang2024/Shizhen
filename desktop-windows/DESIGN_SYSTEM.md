# 拾帧 Windows 视觉规范

界面定位为“清澈、克制的现代桌面媒体工具”。应用图标的天蓝、冷白、海军蓝与灰紫被抽象为界面配色；人物图像本身只用于 Windows 图标，不在任何普通页面中显示。

## 色彩

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | `#F5FAFF` | `#071521` |
| 卡片 | `#FFFFFF` | `#0E2236` |
| 次级容器 | `#E8F5FF` | `#15314A` |
| 主色 | `#138FD3` | `#53BEF0` |
| 主色按下 | `#0A6FA8` | `#2FA8DE` |
| 主文字 | `#10233D` | `#EDF8FF` |
| 次文字 | `#52657A` | `#B7CDDC` |
| 边框 | `#C7DDEC` | `#294960` |
| 灰紫强调 | `#6574A6` | `#93A1D1` |

成功、警告和错误使用独立的语义绿、琥珀与红色，不复用品牌蓝。

## 排版与布局

- 字体：Segoe UI、Microsoft YaHei UI，无装饰字体。
- 页面标题 26px SemiBold，模块标题 18px SemiBold，正文 14px，辅助信息 12–13px。
- 8px 网格；页面边距 24px；卡片内边距 20px；圆角 14px。
- 控件最低高度 42px，图标按钮点击区至少 44px。
- 1024px 以上使用 220px 左侧导航；窄窗口时隐藏副标题并允许内容滚动。
- 技术 URL、format id、请求详情默认折叠。
- 所有状态同时使用图标/文字，不能只依赖颜色。
- 支持键盘焦点、Tab 顺序、屏幕阅读器名称、200% 字体缩放与高 DPI。
