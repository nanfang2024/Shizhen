# 拾帧 Windows 已知限制

## 平台解析

- 解析能力取决于公开页面结构、yt-dlp 版本和用户网络出口。平台更新后可能需要同步更新 yt-dlp 或解析插件。
- 不导入浏览器 Cookie、不登录账号，也不绕过年龄、地区、付费、会员、私密内容、DRM 或机器人验证。
- Instagram 公开 `p` 图片帖和图集会通过专用解析器只读取当前帖子的原尺寸候选，Reel 视频继续使用 yt-dlp；私密帖、Stories、Close Friends、年龄限制或匿名频率限制仍不支持。Facebook、小红书、快手、豆包等平台可能只向未登录访问者公开封面或部分资源；程序不会把封面冒充视频。抖音和 B 站已增加匿名公开作品解析器，但页面结构变更后仍可能需要更新。
- 快手专用解析器优先读取移动分享页公开的 `INIT_STATE`，并把最终移动作品页作为媒体下载 Referer；页面未下发结构化媒体时才回退到匿名公开接口。平台仍可能按出口 IP 要求滑块/反爬验证，此时程序保留准确提示，不会自动处理或绕过验证码。
- Facebook 公共视频继续由 yt-dlp 解析。平台明确返回“仅注册用户可用”的作品不是公开资源，本工具会直接显示登录/访问限制，不使用 Cookie 或其他方式绕过。
- YouTube 需要 Deno 处理公开页面的 JavaScript 挑战；部分出口 IP 会被 YouTube 要求机器人验证。匿名客户端重试仍失败时仅提示“请更换节点重试”，工具不会要求或导入账号 Cookie。
- B 站只显示匿名公开接口实际返回的清晰度；需要登录、大会员或付费权限的清晰度不会展示。对本次测试作品 `BV1LsMk6vE5f`，源作品尺寸为 3840×2076，但匿名播放接口实际只返回 720P、360P；界面会说明 1080P/4K 限制，不会生成不可下载的假选项。
- 通用网页解析器只读取当前响应中的公开直链、Open Graph 和静态媒体字段，不执行站点私有脚本，也不采集推荐区或评论区全部资源。
- 平台返回的媒体可能已经包含作者上传或平台叠加的水印。程序不会通过裁切、修补或重绘删除画面内容，也不会把带水印资源标成“无水印”。
- 公开音乐页面可能只提供试听片段；程序会标注“仅试听片段”，不能获得平台未公开的完整歌曲。

## Windows 集成

- 当前提供无管理员权限的 PowerShell 安装脚本和便携 ZIP，没有 MSIX 商店包、自动更新器、Explorer 右键菜单或 Windows Share Target。
- 可通过剪贴板、文本拖放或 `Shizhen.exe "分享文字 https://example.com"` 传入链接。
- “分享文件”使用系统文件/资源管理器能力；第一版没有在应用内实现联系人或社交应用分享面板。
- 本地预览依赖 Windows 自带媒体解码器；某些罕见编码会提示无法应用内播放，但缓存或下载文件仍可交给其他播放器。
- 任务状态会写入 SQLite。应用异常退出后，未完成任务会在下次启动标为“意外中断”，但不会自动续传 FFmpeg 转换。

## 体积与性能

- 自包含包包含 .NET 8、yt-dlp、Deno、FFmpeg 和 FFprobe，因此体积较大。
- 4K 视频、长 GIF 和高频抽帧可能占用大量 CPU、内存和磁盘空间；处理速度取决于电脑性能。
- 当前 FFmpeg 命令使用 CPU 编码以保证兼容性，没有启用 NVIDIA/AMD/Intel 硬件编码选项。
- 下载前可依据已知大小检查空间；平台未提供大小时只能保留最低安全余量，不能精确预测最终合并文件大小。
