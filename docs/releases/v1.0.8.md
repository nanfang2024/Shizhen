## 拾帧首次公开发行

拾帧是一款面向公开媒体和本地文件的 Android 提取、下载与格式转换工具。文件转换只在手机本地完成。

### 本版本包含

- 从分享文字提取链接，并从其他 App 接收文本分享。
- 公开视频、图片、GIF、封面和音频的解析、预览及后台下载。
- 同一视频或音频的质量选择，以及完整音频/试听片段的明确标识。
- 视频转 GIF、GIF 转 MP4、视频提取 JPG/PNG。
- 下载与转换历史、任务进度、取消、打开、分享和诊断报告。

### 安装要求

- Android 8.0（API 26）或更高版本。
- 64 位 ARM 手机（`arm64-v8a`）。
- 下载 `Shizhen-v1.0.8-arm64-v8a.apk`，并核对 `SHA256SUMS.txt`。

### 使用边界

只处理你拥有版权、已获授权或平台明确允许保存的公开内容。本应用不提供 Cookie 导入、账号登录、付费绕过、DRM 绕过或访问控制规避能力。平台网页结构、地区限制和网络出口可能影响解析结果。

遇到问题时，请在应用“历史记录 → 诊断中心”导出脱敏报告，并通过仓库的问题报告模板反馈。
